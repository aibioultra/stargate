워케이션챌린지① 팀 허브 · 배포 안내 (stargate-aibio.vercel.app/team/)

[하는 일]
- 팀을 고르고 팀 코드(4자리)를 넣으면: 팀원 사전과제(관심 카드) 보기 / 팀 이름·주제 저장 / 예선·본선 PDF 제출
- 아래 '전체 팀 주제' 보드: 팀 이름·주제·제출 여부가 1분마다 갱신 (프로젝터용 큰 글씨: /team/?view=screen)
- 운영진 화면: /team/?admin=관리자키 → 팀별 코드, 마지막 제출 파일 링크, 마감 후 제출 표시

[1. 서버(구글 Apps Script) 만들기 — 10분]
1. 구글 드라이브에서 새 구글 시트를 만듭니다(이름 예: 워케이션챌린지1_팀허브). ai.bio.engine@gmail.com 계정 권장.
2. [확장 프로그램] → [Apps Script] → 기본 Code.gs 내용을 지우고 '팀허브_AppsScript_Code.gs' 내용을 통째로 붙여 넣고 저장.
3. 위 함수 목록에서 setup 선택 → [실행] → 권한 허용(고급 → 안전하지 않음으로 이동 → 허용).
   → 시트에 팀·팀원·제출·안내 탭, 드라이브에 '워케이션챌린지1_팀제출'(예선/본선) 폴더가 생깁니다.
   → '안내' 탭에 관리자 키와 운영진 화면 주소가 적힙니다.
4. [배포] → [새 배포] → 톱니바퀴에서 '웹 앱' → 실행 사용자: 나 / 액세스 권한: 모든 사용자 → [배포]
5. 나온 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.

[2. 페이지 올리기]
1. team/index.html 을 열어 Ctrl+F로 "API: ''" 를 찾아 따옴표 안에 위 URL을 붙여 넣고 저장.
2. https://github.com/aibioultra/stargate → [Add file] → [Upload files] → 'team' 폴더를 통째로 끌어 놓기 → Commit changes.
3. 1~2분 뒤 https://stargate-aibio.vercel.app/team/ 에서 열립니다.
   (URL을 넣기 전에는 '시험 모드'로 예시 팀 2개만 보입니다. 팀 코드 0000)

[3. 당일]
- 팀테이블카드_팀코드_A4.pdf 를 출력(6쪽, 한 쪽에 4팀)해 잘라서 팀 테이블마다 놓습니다. QR을 찍으면 팀 허브로 갑니다.
- 팀 코드는 팀구성명단.xlsx의 '팀 코드' 탭에도 있습니다.
- 예선 15:55쯤 운영진 화면에서 제출 현황을 확인하고, 파일 이름을 눌러 발표용 노트북에서 엽니다.
  (제출 파일은 '링크가 있는 사용자: 보기'로 공유됩니다. 원치 않으면 Code.gs 의 SHARE_FILES 를 false 로)

[알아 둘 점]
- 파일은 PDF만, 20MB까지. 다시 올리면 마지막 파일이 기준이며 이전 파일도 드라이브에 남습니다.
- 파일 이름은 자동으로 트랙_팀번호_팀이름_단계.pdf (팀 이름을 먼저 저장해야 올릴 수 있음).
- 마감 뒤에도 제출은 받고 '마감 후'로 표시합니다.
- 팀원 카드 내용은 팀 코드를 아는 사람만 볼 수 있습니다. 팀 목록·팀 이름·주제·제출 여부는 누구나 봅니다.
- Code.gs 안에 팀원 이름·사전과제 내용이 들어 있으니 외부에 공유하지 마세요.
- 코드를 고친 뒤에는 [배포] → [배포 관리] → 연필 → 버전 '새 버전'으로 다시 배포해야 반영됩니다(주소는 그대로).
